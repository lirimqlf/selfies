📸 SelfieBot

SelfieBot est un bot Discord de modération pour les salons réservés aux selfies : il vérifie que chaque message contient une image, ouvre un fil de discussion sous les selfies valides, et avertit puis met en sourdine temporairement les membres qui postent sans photo.
